# Стрекоза — игра Егора

Раннер для телефона. Стрекоза летит над лугом, тап — прыжок через препятствие.
Держи палец дольше — прыгнет выше. Скорость растёт, рекорд запоминается.

Играть: https://gav26512.github.io/egor-game/

На телефоне можно добавить на домашний экран — откроется как приложение, без адресной строки.

## Локально

```bash
python3 -m http.server 8080
```

Открыть http://localhost:8080. На компьютере прыжок — пробел или стрелка вверх.

## Устройство

- `index.html`, `css/style.css`, `js/game.js` — вся игра, без сборки и зависимостей.
- `manifest.webmanifest`, `icons/` — установка на домашний экран (PWA).
- Сложность настраивается в `CFG` в начале `js/game.js`.
