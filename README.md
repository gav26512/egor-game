# Стрекоза — игра Егора

Раннер для телефона. Стрекоза летит над лугом, тап — прыжок через препятствие.
Держи палец дольше — прыгнет выше. Скорость растёт, рекорд запоминается.
Три жизни: рогоз, кусты, камни и чёрные облачка отнимают по одной, сердечки возвращают.
Золотые облачка дают монетки, копилка хранится между играми.
Двадцать уровней: у каждого свой финиш с клетчатым флажком, дальше быстрее и теснее.
Десятый и двадцатый — болото с лягушкой: перед выстрелом языком над ней появляется «!», увернуться
можно прыжком; на десятом восемь выстрелов, на двадцатом десять, иногда два подряд. Пережил все —
лягушка сдаётся, финиш; после двадцатого победа.
Над некоторыми преградами висит чёрное облачко — проскочить можно только коротким прыжком.
Пройденный уровень запоминается: после проигрыша начинаешь его же, а не первый.
В магазине за монеты продаются 25 расцветок стрекозы: красная и изумрудная по 50; золотая, синяя,
фиолетовая, розовая, оранжевая, огненная (с пламенем), водяная (с пузырьками), жёлтая, лаймовая,
зелёная, мятная, голубая, индиго, пурпурная, малиновая, коралловая, коричневая, белая, серебряная,
серая и чёрная по 100; радужная, переливающаяся всеми цветами, — 300.
Кнопка ⏸ (или Escape) открывает меню паузы: продолжить или выйти в главное меню; забег сохраняется.
Игра спрашивает имя; у каждого телефона свой код игрока, и продолжение (уровень, очки,
жизни, монеты) хранится на нём. Таблица результатов пока локальная — только игроки этого телефона.

Играть: https://gav26512.github.io/egor-game/

На телефоне можно добавить на домашний экран — откроется как приложение, без адресной строки.

## Локально

```bash
python3 -m http.server 8080
```

Открыть http://localhost:8080. На компьютере прыжок — пробел или стрелка вверх.

## Устройство

- `index.html`, `css/style.css`, `js/game.js` — вся игра, без сборки и зависимостей.
- `manifest.webmanifest`, `icons/` — установка на домашний экран (PWA).
- Сложность настраивается в `CFG` в начале `js/game.js`.
